            Cómo reproducir
            
        
            Requiere Python 3.12. El pipeline lee el Excel de data/raw/, aplica las reglas, regenera los JSON de site/data/ y las pruebas comparan los resultados con los valores de control del reglamento.
            

            pip install -r requirements.txt
python pipeline/build.py
pytest
            
      
            

      
            
        
            Uso de IA
            
        
            Este proyecto se construyó con ayuda de Claude (Claude Code): análisis de los datos, pipeline en Python y este sitio. Los valores se verificaron contra los datos reales antes de publicarse: los valores de control del reglamento corren como pruebas automáticas (pytest) y las cifras del sitio salen del pipeline.
            
        
            Los supuestos y el contenido de la Parte 2 los decidió y validó la persona que entrega la prueba. Los errores que aparecieron en la revisión (por ejemplo, una causa raíz mal atribuida en la Parte 2) se corrigieron y quedan en el historial de commits.
